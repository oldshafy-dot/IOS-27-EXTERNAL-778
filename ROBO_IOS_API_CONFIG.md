# ROBO iOS API configuration

This build uses the public client endpoints supplied for ROBO iOS.

Base URL: `https://shafaykeyauthadmin.lovable.app`

- License verification: `POST /api/public/v1/verify-license`
- Patch options: `GET /api/public/v1/patch/options`
- Free Fire UI -> `free_fire_india`
- Free Fire Max UI -> `BGMI`

Reseller endpoints are not used.

The patch UI displays the API `name` field. The API `file_name` field is not shown in the UI.
